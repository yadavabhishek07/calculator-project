# Web Calculator

A clean, responsive, and functional web-based calculator built using vanilla HTML5, CSS3, and JavaScript.

---

## Features

- **Standard Arithmetic**: Addition, subtraction, multiplication, and division.
- **Display Operations**: Clear (`C`) and Backspace (`←`) controls.
- **Decimal Calculation**: Full floating-point math support.
- **Responsive Layout**: Centered card design styled with clean CSS Grid and modern button interactions.

---

## Tech Stack

- **HTML5**: Semantic document markup and calculator structure.
- **CSS3**: Grid layout, button states, and styling.
- **JavaScript (ES6+)**: Calculation engine and DOM manipulation.

---

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/yadavabhishek07/calculator-project.git
cd calculator-project
```

### 2. Run the application
Open `index.html` directly in any web browser or use VS Code Live Server.
